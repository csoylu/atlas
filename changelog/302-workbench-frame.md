## Changed · #302 · The right pane's head row now has a + to open any artifact of the project, and on a phone one tab picker lists every tab

First part of the workbench (#300): the frame that files and web pages will join.

- Tabs carry a kind (artifact today; file and browser come next) and stay stored per chat, the active one included, so a restart brings the pane back as it was.
- + after the tabs opens a menu with a « Find an artifact » filter and the project's artifacts, latest first; pick one and it opens as a new tab.
- On a phone the tabs fold into one picker (« title · N tabs »): each tab with its ×, the active one marked; the version picker stays in the row.
