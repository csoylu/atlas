## Added · #304 · Comment mode in the right pane: press C (or the Comment button), click or drag on a document, image or page, and your numbered notes go with your next message, each telling the agent exactly where.

- Markdown: select text or click a block (section, source lines and quote are sent). Html pages: hover outlines an element, a click pins it, a drag picks an area (selector and text). Svg: click a shape or drag an area (element, shapes inside, coordinates and a cropped picture). Images and image links: drag an area (coordinates and a cropped picture).
- Several comments before sending: numbered chips in the composer, cards in the sent message (thumbnail or quote); a click on a card opens the place. Esc leaves comment mode; C typed in a text box does nothing. On a phone the comment box is a bottom sheet.
- Replaces « Ask about this »: old ❝ messages still show as before. Comments are stored with the message, so a restart or a rewind keeps them.
- Code files get line comments once the code tab (Workbench 2/5) is in; the engine already takes a file and a line range.
