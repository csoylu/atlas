## Added · #305 · The agent now knows which tab is open in your chat's right pane when you send a message: an eye with the tab's name next to the context ring, a click leaves it out of that one message.

- The message carries one short line, never the content: title, path and version for an artifact, the number for a task open beside the chat (path and visible lines for a file, url and title for a web page, once those tabs land). It is said only when it changed since your last message, so the prompt stays small.
- Stored with the message: under it, a quiet « … was open » line. Voice messages (🎙) carry it too, from what the pane shows on screen.
