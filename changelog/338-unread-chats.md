## Added · #338 · Chats with an agent's reply you haven't read show a dot, a « New » line, a desktop notification and a count on the Dock and in the title

### Details
- A chat whose agent replied while you weren't looking: bold name and a teal dot in the sidebar, the Chats tab and
  History; a folded project shows one dot. Only the agent's final reply counts (questions included), never tool steps,
  streaming text or task notes. A chat you are looking at with Atlas in front never turns unread.
- Opening it scrolls to the first unread message under a « New » line, which stays until you leave the chat. Right-click
  a row (long-press on phone): Mark as read, Mark all as read. Read state lives in the engine: desktop and phone agree.
- A desktop notification (agent · project, the first lines of the reply) when Atlas is in the background or another
  chat is open; clicking it opens the chat at « New ».
- The Dock icon and the window title « (N) Atlas » count unread chats plus the Inbox.
- Settings → Appearance → Notifications: one switch for the notification, one for the count (both on by default).
